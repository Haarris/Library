Prepare this machine so vault2okf can check OKF bundles.

- Python 3.10 or newer is installed. Confirm with `python3 --version`.
- The `vault2okf` command line tool is installed. Confirm with `vault2okf --version`. If it is missing, ask the user whether to install it with `pipx install vault2okf` (or `uv tool install vault2okf`), wait for their answer, then confirm again.
- `git` is installed. Confirm with `git --version`.

Do not check or change any bundle during setup. Preparing the machine is the whole job.
