Prepare this machine so the CacheCanary checks can run.

- Python 3.10 or newer is installed — confirm with `python3 --version`.
- The `cachecanary` command-line tool is installed — confirm with `cachecanary --version`. If it is missing, ask the user whether to install it with `pip install cachecanary` (or `pipx install cachecanary`), wait for their answer, then confirm again.
- `git` is installed — confirm with `git --version`.

AWS credentials are not needed; the bot never calls AWS. Do not check any project during setup. Preparing the machine is the whole job.
